# Easy Claim AI

Two tools:

| Folder | What it does |
|---|---|
| [`billgen/`](billgen/) | Makes fake medical billing statement images + JSON answer files, to train an extraction model. |
| [`claimgen/`](claimgen/) | **Easy Claim AI** — turns a bill (image, JSON, or manual entry) into a CMS-1500 claim (JSON + PDF). |

On Windows, double-click `run.bat` inside each folder. See each folder's README and SPEC for details.

All names, addresses, providers and IDs in the samples are made up.
